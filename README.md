# Shopkart

Shopkart is a modern, responsive E-Commerce web application built with **Spring Boot** and **Java**. It is designed to demonstrate full-stack development capabilities for job interviews.

## Features
* **Authentication:** Secure Customer and Admin role-based login (Spring Security).
* **Shopping Cart:** Add products, view cart, and checkout seamlessly.
* **Smart UI:** Modern Bootstrap 4 design with floating Chatbot, Product Search, Category Sidebar, and Star Ratings.
* **Admin Dashboard:** Manage products, categories, customers, and view real-time sales charts.
* **Persistent Data:** Pre-loaded with 500 real-world products using H2 local file storage.

## How to Run
1. Ensure Java 21 is installed.
2. Run `./mvnw spring-boot:run`
3. Access the site at `http://localhost:8080/welcome`
4. **Demo Customer:** adarsh / adarsh123
5. **Demo Admin:** admin / admin123 (accessible at `/admin/login`)
